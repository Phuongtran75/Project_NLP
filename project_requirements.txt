COMP4020 / COMP5040 – Natural Language Processing Project
Phase 2: Final Report & Code, and Individual Reflection (25%)

Deadline: End of Week 14 (11:59pm), submit on GitHub and Canvas

Purpose
The report and code are the core of your NLP project. They demonstrate your ability to:
Follow a complete NLP pipeline from start to finish
Solve an NLP task using appropriate methods and models
Produce clear, reproducible, and well-documented work
Deliver a working NLP system that runs correctly and produces outputs
Show continuous contribution through GitHub activity
⚠️ Avoid uploading everything in one commit. Commit regularly to show progress.

Phase 2 Marks

A) Final Report & Code
Writing Format and Page Limits
Main Report (5–10 pages):
Covers the full NLP workflow:
Problem definition
Dataset
NLP pipeline
Modelling
Evaluation
Results and discussion
⚠️ All figures, tables, and outputs must be included within this limit

Additional Pages (outside main report)
+1 page: Team information and contribution
+1/2 page per member: Individual reflection (max 250 words each)
+1 page: References
+1 page: Appendix (optional)
+1 page (Bonus only): Description of deployed NLP application
⚠️ Content beyond these limits will not be marked
Font: 12pt Times New Roman
Margins: Normal (~2.5cm)

Suggested Report Structure
Title Page – Project title, team, members
Introduction (1–2 pages)
NLP task definition
Dataset origin and description
Motivation and challenges
NLP Tasks / Research Questions (minimum 1 main task or 3 sub-questions)
For each task or question:
Introduction: Why it matters
Approach: Methods (e.g. TF-IDF, embeddings, BERT)
Analysis: Reproducible code and outputs
Evaluation: Metrics (Accuracy, F1, BLEU, ROUGE, etc.)
Discussion: Interpretation and limitations
Conclusion (1–2 pages)
Key findings
Insights and implications
Pipeline Reflection (1 page)
Demonstrate how you followed the NLP pipeline:
Preprocessing
Representation
Modelling
Evaluation
Team Contribution Statement (1 page)
Individual Reflections
References (1 page)
Appendix (optional)

Code and NLP System Requirement
You must include a working NLP system:
Must run end-to-end
Must take input text and produce output
Acceptable formats:
Command-line tool
Jupyter Notebook
Simple interface
This is a core requirement, not optional.
