## Notebooks Overview

- `create_hidden_state.ipynb`  
  Generates hidden states for visualization and constructs steering vectors.

- `create_steer_vectors.ipynb`  
  Creates steering vectors from the generated hidden states.

- `inference.ipynb`  
  Runs inference on the steered model.

The implementation for hidden state generation, steering vector creation, and inference with vLLM in this project is based on the EasySteer repository by ZJU-REAL:

- vLLM: https://github.com/vllm-project/vllm
- EasySteer: https://github.com/ZJU-REAL/EasySteer
